# Privacy and Safety

All public repository data is fictional. The public profile demonstrates verified/visible status, evidence references, claim-owned metrics, authorized paraphrases, and claim/profile-level `do_not_claim` boundaries without exposing real career history.

The agent does not infer protected attributes, rank candidates, or estimate hiring probability. Unsupported experience remains a visible gap. The project demonstrates a design pattern, not a guarantee that automated resume rewriting is universally safe. Human review remains required before using generated application material.
