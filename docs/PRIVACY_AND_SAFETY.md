# Privacy and Safety Boundary

This repository is intentionally separated from any real resume database or application history.

## Public data policy

Allowed in this repository:

- fictional people and organizations;
- synthetic evidence IDs;
- synthetic job descriptions;
- synthetic evaluation cases;
- generic system architecture;
- code that operates on the public schema.

Not allowed:

- real phone numbers or personal email addresses;
- real unpublished application notes;
- real company-specific application folders;
- private evidence documents;
- real source-claim IDs copied from a private career database;
- credentials, API keys or tokens.

## Why a clean public repository

Redacting a private repository after the fact is risky because sensitive data can remain in Git history, fixtures, logs, generated artifacts or old commits. This showcase therefore uses a clean-room public structure with fictional fixtures from the first commit.
